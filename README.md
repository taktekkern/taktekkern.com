# Taktekkern

En mobilvennlig, statisk firmaside for Taktekkern – membranspesialist på tak og terrasser.

## Før publisering

- Bytt ut telefonnummeret og e-postadressen i `index.html`.
- Legg inn egne bilder under «Prosjekter».
- Koble GitHub Pages til domenet `taktekkern.com` etter at repositoriet er opprettet.

Siden bruker bare HTML, CSS og JavaScript og trenger ingen installasjon.
